# IBM shared hardware firewall deprecation
{: #deprecation-hardware-shared-firewall}

The {{site.data.keyword.cloud}} shared hardware firewall reached End of Marketing (EOM) on 17 December 2025 and no longer accepts new orders. The service will no longer be supported by {{site.data.keyword.cloud_notm}} as of 31 December 2026, and any instances that are still running will no longer receive security updates after this date.
{: shortdesc}

## Important dates
{: #deprecation-timeline}

| Stage | Date | Description |
| ---------------- | ----------------- | ------------------------------------------------------------ |
| Deprecation announcement | 17 December 2025 | Announcement of the shared hardware firewall deprecation. Existing instances continue to run. |
| End of marketing | 17 December 2025 | No new instances of shared hardware firewall can be created or purchased. Existing instances continue to run. |
| End of support | 31 December 2026 | Running instances of shared hardware firewall are no longer supported or updated. |
{: caption="Deprecation timeline for IBM shared hardware firewall" caption-side="bottom"}

## Deprecation details
{: #deprecation-details}

Review the following details about the shared hardware firewall deprecation:

* Effective 17 December 2025, {{site.data.keyword.cloud_notm}} no longer accepts new orders for the shared hardware firewall.
* Any existing instances created before 17 December 2025 continue to run and receive support until 31 December 2026.
* After 31 December 2026, support for shared hardware firewall devices, including updates, bug fixes, and technical support, is no longer available.
* Support cases cannot be opened after 31 December 2026.

For information about migrating your workloads to an alternative firewall architecture, see [Migrate off a shared hardware firewall](/docs/hardware-firewall-shared?topic=hardware-firewall-shared-shared-fw-migration).
